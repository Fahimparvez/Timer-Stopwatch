# Classroom Timer

An ad-free **timer, clock and stopwatch** for the classroom, made to be shown on a projector.
It is a single HTML file: no installation, no internet needed, no tracking.

## Use it

- **Online:** open the GitHub Pages link for this repository.
- **Offline:** download `index.html` and open it in Chrome, Edge or Firefox.

Press **F** for fullscreen. In fullscreen only the time is shown; the buttons fade away
after a few seconds and come back when you move the mouse.

## Features

**Timer**
- Presets (5, 10, 15, 20 min) or any custom time
- +1 / −1 minute while running; +1 min during overtime gives one more minute
- Colour warning: amber in the last minute, red in the last 10 seconds
- "Time's up" flashes with a soft beep for 30 seconds, then counts overtime
- Optional label (e.g. *Group work*) shown above the time

**Clock**
- Large time with seconds and date, 12 or 24-hour
- Alarm at a time of day (soft beep for 30 seconds)

**Stopwatch**
- Tenths of a second and laps

**Everywhere**
- Digital (seven-segment) or Classic digits
- Light and dark theme
- Keeps the screen awake while running
- Remembers your settings in the browser

## Keyboard shortcuts

Press **?** on the page to see this list.

| Key | Action |
| --- | --- |
| Space | Start / pause, or stop a ringing alarm |
| R | Reset |
| F | Fullscreen on / off |
| T / C / S | Timer / Clock / Stopwatch |
| 1 – 4 | Presets: 5, 10, 15, 20 min |
| ↑ / ↓ | Add / remove 1 minute |
| L | Lap (stopwatch) |
| H | 12 / 24-hour clock |
| G | Digital / Classic digits |
| M | Sound on / off |
| D | Light / dark theme |
| Esc | Stop alarm, close help |

## Good to know

- Browsers only allow sound after you click or press a key on the page once.
  If you reload the page with a clock alarm set, click anywhere so the alarm can ring.
- A running timer or stopwatch is not kept if the page is reloaded; settings and a set
  clock alarm are.
